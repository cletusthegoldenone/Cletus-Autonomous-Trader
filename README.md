# Cletus-Autonomous-Trader
Cletus is an autonomous, AI-powered trading system built for the Solana DeFi ecosystem. He hunts low market-cap tokens in the $10,000–$500,000 range — the volatile micro-cap trenches where genuine alpha still exists — and executes trades based on a continuously self-improving pattern intelligence engine.  He is not a human. He is not a fund manage.
